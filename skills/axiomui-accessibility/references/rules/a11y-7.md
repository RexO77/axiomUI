# Underline links in paragraphs

- ID: a11y-7
- Category: Accessibility & inclusivity
- Tags: Accessibility, WCAG, Navigation, Contrast
- URL: https://axiomui.nischal.fyi/rules/a11y-7

Underline links in paragraphs so readers can find them without distinguishing colors. In a navigation menu, placement can identify the links.

- Do: p a { text-decoration: underline }
- Don’t: p a { text-decoration: none } · color only

## Why it works

The sharing guide is linked inside a sentence about file access. The underline marks where the link begins and ends, even when its blue looks like the surrounding ink.

- [WCAG failure F73 · Links identified by color alone](https://www.w3.org/WAI/WCAG22/Techniques/failures/F73)
- [GOV.UK · Links](https://design-system.service.gov.uk/styles/links/)
- [WCAG technique G183 · Contrast with surrounding text](https://www.w3.org/WAI/WCAG22/Techniques/general/G183)
- [Ontario Design System · Links](https://designsystem.ontario.ca/components/detail/links.html)
- [NN/g · Visualizing links](https://www.nngroup.com/articles/guidelines-for-visualizing-links/)

## What breaks

Someone who can’t distinguish the link color may read “sharing guide” without realizing it opens the guide.

## How to apply it

1. Check inline links in paragraphs, lists and captions. Look for no-underline or text-decoration: none in the default and visited states.
2. Keep underlines on prose links at rest. Navigation menus can omit them when placement already makes their links recognizable.
3. If color alone marks an inline link, WCAG technique G183 calls for at least 3:1 contrast with the surrounding text. Check both text colors against the background separately.

## Before you ship

1. Turn on grayscale, move the pointer off the paragraph and read the sentence. Can you find the sharing guide link before interacting with it?
2. Does a visited inline link retain an underline or a sufficient visual cue at rest?
3. If color alone marks a link, does it reach 3:1 contrast with surrounding text before anyone interacts with it?
