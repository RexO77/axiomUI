# Return focus when a dialog closes

- ID: a11y-8
- Category: Accessibility & inclusivity
- Tags: Accessibility, WCAG, Keyboard, Overlays
- URL: https://axiomui.nischal.fyi/rules/a11y-8

When a dialog closes, return keyboard focus to the control that opened it. If that control disappears or the task continues elsewhere, focus the next step.

- Do: Esc → focus returns to “Edit”
- Don’t: Esc, then Tab → focus moves to “New project”

## Why it works

After closing the edit dialog for Quarterly report, someone using a keyboard is still working in that project row. Returning focus to Edit keeps their place so they can continue through the project list.

- [WAI-ARIA APG · Modal dialog pattern](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)
- [WCAG 2.2 · Focus order](https://www.w3.org/WAI/WCAG22/Understanding/focus-order.html)
- [SAP · Focus restore](https://sap.github.io/accessibility-design-tools/doc/Accessibility_Design_Tools_Second_Edition.pdf#page=121)
- [Adobe React Aria · FocusScope](https://react-aria.adobe.com/FocusScope)
- [WHATWG HTML · Hiding a popover](https://html.spec.whatwg.org/multipage/popover.html#hide-popover-algorithm)

## What breaks

If focus falls back to the page body, the next Tab can land on New project at the top and make the user search for the row again.

## How to apply it

1. Use your dialog component’s built-in focus restoration if available. For a custom dialog, save the opener and focus it once the page behind the dialog can receive focus again.
2. Check document.activeElement after Escape, Cancel and Save. If focus falls to the page body or the next Tab jumps to the first control, check where the dialog restores focus.
3. If deleting a row removes its Edit button, focus Edit in the next row. Use the previous row if you deleted the last one, or New project if the list is empty.

## Before you ship

1. In your project list, open an edit dialog with the keyboard and press Escape. Is focus back on the row’s Edit button before you press Tab again?
2. Do Cancel and Save also put focus where the task should continue?
3. If your dialog can delete a row, try deleting the last one. Can you continue from the previous row or, in an empty list, from New project?
