# Pair color with another cue

- ID: a11y-2
- Category: Accessibility & inclusivity
- Tags: Accessibility, Icons, Semantics
- URL: https://axiomui.nischal.fyi/rules/a11y-2

If color marks an error, state or category, add a label, icon or pattern with the same meaning. For a form error, name the field and explain the problem in text.

- Do: Red border + error icon + message
- Don’t: Only a red border on the input

## Why it works

“Card number needs 16 digits, not 14” tells the reader which field to fix and why. The icon helps them find the message even in grayscale.

- [WCAG 2.2 · Use of color](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html)
- [WCAG 2.2 · Error identification](https://www.w3.org/WAI/WCAG22/Understanding/error-identification.html)
- [Adobe Spectrum · Color](https://spectrum.adobe.com/foundations/color/color)
- [GOV.UK · Error message](https://design-system.service.gov.uk/components/error-message/)

## What breaks

In grayscale, the red border looks gray. Without a message, the reader has to guess what’s wrong with the card number.

## How to apply it

1. Use text, shape, pattern or another suitable cue for the meaning carried by color.
2. Explain the error in text and connect the message to the field, for example with aria-describedby.
3. View the field in grayscale. Then focus it with a screen reader and listen for the error message.

## Before you ship

1. Can you tell the two states apart in grayscale?
2. Does the message explain what needs correcting?
3. When you focus the field with a screen reader, do you hear the error message?
