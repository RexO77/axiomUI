# How the skills apply the rule library

The review compared the eight domain descriptions and introductions with their rule entries. It also followed the instructions an agent receives from the rule library, audit, upgrade playbook and standalone playbook download.

| Earlier instruction | Editorial decision and evidence |
| --- | --- |
| Apply each Do verbatim and report matching a Don’t as a violation. | A sample duration demonstrates a treatment. A WCAG threshold has a conformance level, scope and exceptions. The library and domain templates now ask readers to identify which kind of claim they are applying. The audit requires an observed failure or a measurement and records the conditions of a standards finding. [WCAG minimum text contrast](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) |
| Set each type value once, left-align multiline copy and use sentence case across the interface. | The typography guidance now asks for a real string, script, role and size. The upgrade playbook aligns paragraphs to their reading start and scopes sentence case to ordinary English labels. This matters when an interface contains a translated label, an official product name or a name written in the opposite direction. [W3C document direction](https://www.w3.org/International/questions/qa-html-dir) · [Microsoft capitalization](https://learn.microsoft.com/en-us/style-guide/capitalization) |
| Apply a 60–30–10 palette and derive all states from the base color. | The color skill now describes accent, interaction and status roles. It calls for measuring a text or control color on its rendered background. The percentages in the example do not determine those measurements. [Atlassian color roles](https://atlassian.design/foundations/color) |
| Adopt the example timings unchanged and always shorten the exit. | The motion skill and upgrade playbook now ask what the movement communicates, how often the action repeats, and what happens on interruption. Review entrance and exit separately. Carbon distinguishes productive and expressive movement and scales durations with the change. [IBM Carbon motion](https://www.carbondesignsystem.com/building-blocks/foundations/motion/overview) |
| Emphasize exactly one action per screen and make whole cards clickable. | The component guidance scopes prominence to a task group and preserves distinct targets for independent actions. For example, a card’s details link and Archive button must remain separately operable. [HTML anchor content model](https://html.spec.whatwg.org/multipage/text-level-semantics.html#the-a-element) |

The detailed reference installed with each applicable skill includes that rule’s primary sources immediately after its explanation. The full Markdown corpus uses the same serializer. Source links come from the same per-rule registry as the site. A generated-reference test compares every rule’s source lines with its registry entry and checks that all installed copies of each rule are identical.
